三友ワークス  Ver. 2.9.4（試作）
株式会社三友製作所 ものづくり体験ゲーム

新人として、マスコットの「さんぽぽ」を1つ、設計から出荷まで作り上げる
仕事体験シミュレーションゲームです。1回 約10分。

  設計開発部門 …… 1 仕様決め　 2 設計　　　　 3 検査（検図）
  機械加工部門 …… 4 加工・仕上げ　　　　　　　5 検査（寸法測定）
  組立調整部門 …… 6 組立　　　 7 調整　　　　 8 検査（出荷検査）

各作業は、制限時間内に終わらせればクリアです。ミスが少なく早いほど★（最大3つ）が増えます。


■ 遊び方
  フォルダを展開（解凍）して、index.html をダブルクリックするとブラウザで開きます。
  インターネットにつながっていなくても、すべての機能が動きます。
  ※ zip のまま開くと画像や音が読み込めません。必ず展開してから開いてください。
  ※ フォルダの中のファイルの場所や名前は変えないでください。

■ スマートフォンで遊ぶとき（Ver. 2.6 から）
  ・1ファイル版（sanyu_works_v2.9.4_スマホ用.html）を使ってください。画像・音声・フォントをすべて1つのファイルに入れた版です。
      このフォルダには入っていません（別のファイルで配ります）。作り直すときは python tools/build_1file.py を実行します。
      スマートフォンに送って（メール・LINE・USB・Googleドライブなど）、Chrome で開くだけで遊べます。
      ※ スマートフォンでは、展開したフォルダの index.html を開いても、となりのフォルダ（js・img など）を
        読みこめずに動かないことがあります。そのときも 1ファイル版なら動きます。
  ・いちばん確実なのは、Webサイト（https のページ）に置いて、そのURLを開く方法です（下の「Webサイトに載せるとき」）。
  ・スマートフォン（画面の短い辺が 600px 以下の、指で操作する端末）では、スマホ専用の画面になります。
    タブレット（iPad など）は、パソコンと同じ画面を指で操作します。
      最初に「画面をタップしてスタート」→ 全画面・横向きになります（全画面をやめると「全画面にもどる」が出ます）。
      iPhone は全画面のしくみがないので、共有ボタン →「ホーム画面に追加」から開くと全画面になります。
  ・ゲーム画面は、どこも見切れない範囲でいちばん大きく表示します。上の帯（時計・残り時間・★）と下の説明は出しません。
    16:9 より横長のスマホ（Galaxy A55 など）では左右に余白ができ、☰ はその余白に出ます。
  ・左上の ☰ メニューに、まとめています（開いているあいだは時間が止まります）。
      残り時間と★ ／ いまやることを見る ／ 元の大きさにもどす（2本の指で拡大したときだけ） ／
      音量（消音・小・中・大）／ 操作の説明 ／ 一時停止・やり直し ／ 全画面にする・やめる
  ・2本の指で広げる・つまむ・動かすと、ゲーム画面を拡大（最大3倍）・縮小・移動できます。
    ☰ の「元の大きさにもどす」で元にもどります。
  ・CADのスケッチ・穴あけは、指の少し上が「ねらう点」になります。押したまま動かして位置と数字を合わせ、
    指をはなすと決定します（穴あけ）。
  ・ボタンは、指をはなしたときに決まります（ずらしてはなすと取り消し）。少し外れても、近いボタンが押されます。
  ・「いまやること」と操作の説明は、作業が変わったときだけ右上に数秒出ます（さわれないので、下のボタンはそのまま押せます）。
    ☰ の「いまやることを見る」でもう一度見られます。
  ・ホーム画面に追加すると（Chrome のメニュー →「ホーム画面に追加」）、アプリのように全画面・横向きで起動します
    （Webサイト版のみ）。
  ・ファイルを直接開いたときは、ランキングなどの記録が端末に残らないことがあります
    （遊んでいるあいだは覚えています）。イベントで記録を集めるときは、パソコンか Webサイト版を使ってください。
  ・1ファイル版を作り直すとき：python tools/build_1file.py（プログラムを直したあとに実行）

■ 操作（パソコンが基本です）
  キーボード …… 矢印キーでえらぶ ／ Enter（または Space）で決定 ／ 数字キーで番号のボタンを直接えらぶ
                「押しつづける」作業は Enter か Space を押しつづける ／ Esc で一時停止
  マウス …… 画面のボタンをクリック（押しつづける作業は、ボタンを押したままにする）
  タッチ …… スマートフォン・タブレットは横向きで、マウスと同じように遊べます
  キーボードだけ、マウスだけ、どちらでも最初から最後まで遊べます。

■ 動作環境
  ・パソコンの Chrome・Edge・Safari の新しい版を推奨
  ・立体（3D）の表示には WebGL を使います。使えない端末では、自動でさんぽぽの絵に切りかわります（遊ぶことはできます）

■ Webサイトに載せるとき
  このフォルダの中身をそのままサーバーに置くだけで動きます（サーバー側のプログラムは不要）。
  さんぽぽの声を使う場合は、そのページにも「VOICEVOX:ずんだもん」と書いてください。

■ Ver. 2.5 で変わったこと（Ver. 2.4 から）
  ・設計（3D CAD）で作る形を、完成品のさんぽぽと同じにしました。
      三角パーツは、体から出ている棒（ピン）の先についています。CADにも「ピンを押し出す」工程を加えました。
      機械設計は 7 ステップ：スケッチ（正面に半だ円 幅65・高さ60）→ 回転（360°）→ 押し出し（ピン Φ2・長さ14 mm）
        → 押し出し（三角 厚さ4 mm）→ 円形パターン（ピンと三角の組を5つ）→ 穴あけ（Φ6、横6・上6 mm）→ ミラー。
      制限時間は 210秒にしました。
  ・スケッチやミラーで面をえらぶところを、カード（立方体の絵と「顔が見える向きの面」などの説明つき）にしました。
      カードにマウスを乗せる（または矢印でえらぶ）と、その面だけが3Dの画面でオレンジ色になります。
  ・加工の「材料を固定する」で、締める強さのメーターがボタンにかくれていたのを直しました。
      緑のはんい（60〜75%）が光り、「緑で手をはなす」「締めすぎ」の説明が出ます。
  ・寸法をすべてそろえました（設計指示書・CAD・立体のさんぽぽ・検図の図面・寸法測定）。
      体：幅 65 mm・高さ 60 mm　ピン：Φ2・長さ 14 mm　三角パーツ：厚さ 4 mm（5組・50° おき）
      目の穴：Φ6、中心から横 6 mm・上 6 mm（中に LED）。model/sanpopo.obj もこの寸法で作り直しました。

■ Ver. 2.4 で変わったこと（Ver. 2.3 から）

■ イベント（展示会・会社説明会）で使うとき
  1. 「設定」→「イベントモード」を ON にする
  2. 右上の四角い矢印のボタンで全画面にする
  3. 終わったら「設定」→「スタッフメニュー」を長押しで開き、「CSVで書き出す」でアンケートを保存
  4. 次のイベントの前に「回答をすべて消す」（2回押すと消えます）
  ※ イベントモード中は、最後の画面の「採用ページ」ボタンは出ません（ゲームから離れないように）。

■ アンケートをサーバーで集めたいとき
  js/survey.js の SW.surveyStore を差し替えます。
    save(record) … 回答1件を保存（今は端末内。サーバーへ送る処理に変える）
    list()       … 保存済みの回答の一覧
    clear()      … 全消去
  1件の回答（record）の形：
    {
      "schema": "sanyu-works-survey/3",   ← Ver. 2.3 で 3 に（answers に comment が入ることがある）
      "id": "回答ID",
      "answeredAt": "2026-11-12T10:00:00.000Z",
      "answers": { "occupation":"大学生", "age":"19〜22歳",
                   "understand_work":4, "understand_tech":5, "understand_flow":3,   ← 理解度は1〜5
                   "comment":"機械で削るところが楽しかった" },   ← 感想（任意。空のときは comment がない）
      "game": { "mode":"course", "total":18（★の合計）, "clears":8, "time":412（作業時間の合計・秒）,
                "scores":{"spec":3,"design":2,...}（作業ごとの★。0は時間切れ）, "job":"機械設計エンジニア", "durationSec":620 },
      "client": { "app":"sanyu-works", "version":"2.9.4" }
    }
  名前は保存していません。ただし感想は自由に書けるので、名前などが書かれることがあります（納品前チェックリスト 8）。
