ゲームで使う文字のフォントです。インターネットがなくても同じ見た目になるように同梱しています。

・SWSans-Regular.woff / SWSans-Bold.woff
  Noto Sans CJK JP から、必要な文字だけを取り出したものです
  （SIL Open Font License 1.1。OFL-NotoSansCJK.txt を参照）。

  入っている文字：ひらがな・カタカナ・英数字・記号・JIS第1水準の漢字（約3,000字）と、ゲームの文章で使っている文字。
  セリフや社員カードを書きかえても、ふつうの漢字ならそのまま同じフォントで表示されます。
  めずらしい漢字（人名用の異体字など）だけ、端末のフォントで表示されることがあります。

※ Ver. 1.0 から、ドット風フォント（DotGothic16）とインターネットからの読み込みは使っていません。
