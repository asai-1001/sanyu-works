三友ワークス Ver. 2.9.4　納品・公開の前に、人の確認が必要なこと

[ ] 1. BGMと効果音を、実際に耳で聞いて確認
        音はプログラムで鳴らしています。制作時は自動テストで動作のみ確認しており、聞こえ方は確認できていません。
        合わない場合は、設定でOFFにするか、js/core.js の BGM（音の並び）を調整してください。

[ ] 2. さんぽぽの声（43本）の確認
        Ver. 2.3 から 001.mp3〜043.mp3 を同梱しています。差しかえるときは、同じ名前で voice フォルダに入れてください。
        入れたあと、一日コースを1回通して、セリフと声が合っているかを確認してください。
        特に 019・020（仕上げの説明）は、作業4の途中（削り終わったあと）で流れます。

[ ] 3. VOICEVOX ずんだもんの利用規約
        ・クレジット「VOICEVOX:ずんだもん」は、クレジット画面と設定画面に入れてあります。消さないでください。
        ・Webサイトに載せる場合は、そのページにも同じ表記を入れてください。
        ・ずんだもんの声を、会社のマスコット「さんぽぽ」の声として使うことについて、公式の規約とQ&Aには
          はっきりした記載が見つかりませんでした。気になる場合は、東北ずん子・ずんだもんプロジェクトに問い合わせてください。
        ・画面に「VOICEVOX:ずんだもん」と出ることを、三友製作所が了承しているか確認してください。
        規約：https://zunko.jp/con_ongen_kiyaku.html　Q&A：https://zunko.jp/guideline_qa.html

[ ] 4. 立体のさんぽぽの見た目
        球や三角の板を組み合わせて、プログラムで作ったモデルです。公式の絵とは印象がちがいます
        （金属の体、三角パーツを細い棒で支える形）。会社に見てもらってください。
        制作資料の model/sanpopo.obj を Blender などで開いて、手直しすることもできます（ゲームへの反映は別作業です）。

[ ] 4-2. 衣装のさんぽぽの絵
        いただいた4枚の画像は、罫線のある紙の上の絵だったので、背景と罫線をプログラムで消して切り抜きました。
        小さく表示するぶんには問題ありませんが、ふちや、ひげの先に少し欠けや線の残りがあります。
        罫線のない元のデータがあれば、img フォルダの sanpopo_dev.png（書類）／ sanpopo_mc.png（保護めがね）／
        sanpopo_as.png（ドライバー）／ sanpopo_help.png（スパナ）を、同じ名前で置きかえてください。
        ※ 音声の 020「力を入れすぎるとキズになる。ちょうどいい力で…」は、みがきの操作を「こする」に変えたため、
          画面の操作（力のゲージなし）と少し合わなくなっています。気になる場合は、セリフと音声を直してください。

[ ] 5. 作業の中身の監修
        一般的な内容をもとに、ゲーム用に単純化しています。実際の手順とちがう点がないか、各部門の方に見てもらってください。
        ・仕様決め：お客様の要望と選択肢（材料を黄銅にする理由など）
        ・設計：3D CADの手順（Ver. 2.5）。正面に半だ円をスケッチ → 回転 → ピンを押し出し → 三角を押し出し → 円形パターン → 穴あけ → ミラー の流れと、ツールの名前。
          寸法（体 幅65・高さ60、ピン Φ2・長さ14、三角 厚さ4、目の穴 Φ6 横6・上6 mm）はゲーム用の設定で、
          指示書・CAD・立体のさんぽぽ・検図・寸法測定はすべてこの値にそろえています。実物の寸法に合わせる場合は、js/model.js の先頭と
          js/tasks/cad.js の W_T・H_T・PIN_L・TRI_T・EYE_X・EYE_Y、検図（dev.js）、寸法測定（mc.js）を同時に直してください。
          回路（スイッチ・抵抗・LEDの向き）
        ・検図：図面の書き方、材料の表記（黄銅 C3604、アルミ A5052）
        ・加工：エンドミルΦ10での荒加工、バイスでの固定、エッジファインダーでの原点合わせ
          （測定子の半径ぶんの補正は省いています。タッチプローブを使っている場合は見せ方の相談が必要です）
        ・寸法測定：ノギスとマイクロメータの目もりは、読みやすい直線の目もりに単純化しています（副尺やシンブルは再現していません）
        ・組立：ねじの対角締め（仮締め→本締め）、配線の色と端子
        ・調整・出荷検査：明るさの基準（68〜72%）や検査項目は、ゲーム用の設定です

[ ] 6-2. 社員紹介とVlog（Ver. 2.2）

[ ] 6-3. バリ取りの操作（Ver. 2.3）
        ・マウス、タッチ（タブレット）、キーボードのそれぞれで、ふちをなぞってバリが取れるか、人の手で確かめる
        ・なぞる速さ・バリの大きさ（● の数）・150秒の制限時間が、はじめての人にちょうどよいか
        ・実際のバリ取り（スクレーパーなどの道具でふちをなぞる）の見せ方として、まちがいがないか、加工部門の方に見てもらう
        ・削る音（プログラムで鳴らす音）を、実際に耳で聞いて確認

[ ] 6-4. 設計（3D CAD）の操作（Ver. 2.4）
        ・マウス、タッチ（タブレット）、キーボードのそれぞれで、最後まで操作できるか、人の手で確かめる
          （ドラッグ：半円・回転の角度・押し出しの厚さ・円形パターンの個数・部品の棚　／　クリック：ツール・面・形・LED）
        ・はじめての人が 210秒で終わるか。むずかしければ、dev.js と cad.js の limit:210 を長くする
        ・実際に使っている CAD（ソフトの名前・ツールの名前・画面）に近づけたい点があれば、設計部門の方に見てもらう

        公式ホームページの「設計開発部門・機械加工部門・組立調整部門」を使っています。

[ ] 8. さんぽぽ・社名の使用許可、アンケートと個人情報

[ ] 9. 実機での確認
        制作時は Chrome の自動操作で、次のことを確認しています。
          ・キーボードだけで一日コースを最初から最後まで（8作業〜診断〜アンケート〜修了証）
          ・マウスだけで「加工・仕上げ」を最後まで
          ・時間切れ、やり直し、一時停止、チュートリアル、イベントモードの放置リセット
          ・パソコンの画面、タブレット、スマートフォン横向きの大きさでの表示
          ・3D（WebGL）が使えない場合の表示
        実際に使うパソコンで、人の手で1回通してください。特に次の点は、人でないと分かりません。
          ・制限時間がちょうどよいか（自動操作は人よりずっと速いので、長さの感覚は確認できていません）
          ・説明の文が、はじめての人に伝わるか
          ・古いパソコンで3Dの動きが重くないか

■ スマートフォン（Ver. 2.6〜2.9）
  □ 実際のスマートフォン（Galaxy A55 など）で、1ファイル版（sanyu_works_v2.9.4_スマホ用.html）か Webサイト版を Chrome で開いて、最後まで遊べるか
  □ 横向きで、ゲーム画面が大きく表示され、左右のすきまの時計・ボタンが見やすいか。文字が小さすぎないか
  □ 「画面をタップしてスタート」で全画面・横向きになるか。全画面をやめたとき「全画面にもどる」が出るか
  □ ゲーム画面がどこも見切れずに、画面に収まるいちばん大きいサイズで出るか
  □ ☰ メニューで、音量・説明・一時停止・全画面が使えるか
  □ 2本の指で拡大・移動ができ、☰ の「元の大きさにもどす」で元にもどるか。拡大しようとしてボタンが押されないか
  □ バリ取り・配線などを、指でなぞって操作できるか。CADの穴あけで、数字が指で隠れずに合わせられるか
  □ 「いまやること」のカードが作業の始めに出て、じゃまにならずに消えるか（左の「やること」で再表示）
  □ Webサイト版を「ホーム画面に追加」して、全画面・横向きで起動するか
  □ 最初のボタンで全画面・横向きになるか（ならないときは右の「□」ボタン）
  □ CADのドラッグ・2本指の拡大、バリ取りのなぞり、配線のドラッグ、「押しつづける」ボタンが指で操作できるか
  □ さんぽぽの声・BGMが鳴るか（スマートフォンのマナーモード・音量も確認）
  □ Webサイトに置く場合は、https のURLをスマートフォンで開いて確認
